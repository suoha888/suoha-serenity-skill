# suoha-serenity skill

这是中文入口文档。完整说明请阅读 [README.md](README.md)。当前版本为 v3。

suoha-serenity skill 是独立的、证据优先且具备时间边界的产业链与公司研究
编译器。它将市场叙事拆成系统变化、结构化卡点、公司画像、股价/市值快照、
经济传导、预期差、条件化研究理由、证据、反证和 thesis 生命周期。

机器名称为 suoha-serenity-skill，显示名称为 suoha-serenity skill。项目只
提供研究支持，不执行交易、不预测收益、不输出单一总分或目标价，也不分发
第三方或订阅档案。
