# 更新日志

## 8.0.0 — 2026-10-19

首个正式公开版本。

- 学理论：Serenity 卡脖子理论全书、方法手册和历史案例库，每条规则只附帖子编号。
- 研究个股：A 股、港股、美股任意一只股票，自动抓取 SEC、巨潮、披露易等官方数据，生成可复算、可校验的研究报告。
- 公司体检：按公司类型逐项检查成长、盈利、现金、负债、股东和估值，标出财务红旗，每项附公式。
- 名称识别：支持中文、繁体、英文名称和 A+H、港美两地上市映射。
- 一键安装：`install.sh` / `install.ps1`，支持 Claude Code、Codex 等客户端，不需要 API Key。
