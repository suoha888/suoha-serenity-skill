# suoha-serenity skill

See [README.md](README.md) for the full project guide.

suoha-serenity skill is an independent, evidence-first and time-aware
supply-chain research Agent Skill. It turns a market narrative into a system
change, scarce constraint, economic transmission, company candidates, evidence,
counterevidence, and a dated thesis lifecycle.

The machine name is suoha-serenity-skill and the display name is
suoha-serenity skill. The project provides research support only: no trade
execution, return prediction, or redistribution of third-party or subscription
archives.
