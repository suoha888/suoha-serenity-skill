# suoha-serenity skill v3

See [README.md](README.md) for the full project guide.

suoha-serenity skill is an independent, evidence-first and time-aware
supply-chain and company research compiler. It turns a market narrative into a
system change, a first-class bottleneck assessment, dated company and market
facts, economic transmission, variant perception, conditional research reasons,
evidence, counterevidence, and a dated thesis lifecycle.

The machine name is suoha-serenity-skill and the display name is
suoha-serenity skill. The project provides research support only: no trade
execution, return prediction, target-price promise, single composite conviction
score, or redistribution of third-party or subscription archives.
